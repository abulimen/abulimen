# Hey, I'm Jonathan :) 👋🏽

I'm a software engineering student who likes building things to solve problems.


Most of my projects start with a problem I've run into myself, something I've seen around me, or a question I couldn't leave alone.


Right now, I'm spending most of my time working with PHP, JavaScript, Python and Java, while getting deeper into backend development and system design.


### Things I've built


- A university timetable system that uses constraint solving to automatically create clash-free timetables.


- A class attendance system built around Bluetooth Low Energy to make it harder for students to fake attendance.


- A writing workspace that gives lecturers a clearer view of how students actually produced their assignments, especially when AI and group work make the final document harder to judge.


- An offline-first Computer-Based Examination platform for secondary schools with limited network connectivity.


I've also built an e-commerce website for a client: [Réve Collections](https://revecollections.com).


I enjoy projects that force me to figure things out rather than just follow tutorials.


I'm also learning how to use AI in my development workflow without letting it become a substitute for understanding the code I ship.
